## How to use this file

The entries are in **APA 7**. For a Thai thesis, convert them to the faculty's style. The last section shows the common KMITL-like pattern (`Author. Year. Title. Place : Publisher.` with `[Online]. Available : URL.`). Before citing, open each URL and confirm the page numbers against the publisher's page. Online documents marked n.d. should carry an access date if the style requires one.

```text
Miller, R.B. 1968. "Response Time in Man-Computer Conversational Transactions." 267-277. in

Brooke, J. 1996. "SUS : A 'Quick and Dirty' Usability Scale." 189-194. in Jordan, P.W., Thomas, B.,
    Weerdmeester, B.A. and McClelland, I.L., editors. Usability Evaluation in Industry. London :
    Taylor & Francis.

    Requirements and Evaluation (SQuaRE) — Product Quality Model. Geneva : International
    Organization for Standardization.
W3C. 2023. Web Content Accessibility Guidelines (WCAG) 2.2. [Online]. Available :
    https://www.w3.org/TR/WCAG22/.
พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562. 2562. ราชกิจจานุเบกษา. เล่ม 136 ตอนที่ 69 ก.
```

Pattern: authors with initials. Year. "Article title." pages. in Proceedings or Book. Place : Publisher. Web pages end with `[Online]. Available : URL.` Thai entries come first, then English, each group sorted alphabetically.
