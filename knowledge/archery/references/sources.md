## What is measured and what isn't

- **Backed by a citation in the sources:** sentence headlines are recalled better than short phrases (Alley et al., 2006, via [NIU]).
- **Asserted without one:** every slide-size, line-count and colour-count number; "irrelevant graphics hinder learning"; "multimodal delivery improves comprehension".
- **This skill's own assessment,** and marked as such in each file: the choose-a-method-by-verb table, the slide notes per method, the room-size table for type, the activity timings, the 45-minute split, the AI cautions and the Thai type notes.

## Refreshing this file

Sources rot and guidance changes. To update:

1. Re-read each source **in full**. A summarising tool invents caveats and numbers the article never gave, so don't rely on one.
2. Add new sources with a date, and mark anything you couldn't read completely.
3. Prefer a source that cites research over one that doesn't. If a numeric rule gains evidence, mark it.
4. Update the trust column and bump `metadata.version`.
