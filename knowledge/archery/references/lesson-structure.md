# Lesson structure — from target to a timed outline

The second half of **Aim**. It turns the target and the method into a session where every minute has a job. Only after this do you make slides.

**Provenance:** the skeleton combines the structures given by COMSIAM (school and online teaching) and IT-Guides (business briefings), plus Northern Illinois University's guidance on planning and timing. The worked example and the timing table are this skill's own.

---

## 1. The lesson skeleton

| Block | Job | Source pattern |
| --- | --- | --- |
| **Opening** | get attention; put the objective in front of the learners | a question projected as students arrive; a demonstration as a hook; the objective slide |
| **Content chunk** (repeat) | one idea, explained with an example | one slide, one idea; a chunk is short enough to hold in memory |
| **Activity** | learners do something with the chunk | the method from [teaching-methods](teaching-methods.md), or a moment from [engagement-activities](engagement-activities.md) |
| **Check** | find out whether they got it, before you move on | a question, a poll, a note check |
| **Summary** | the few things to keep | a key-takeaways slide |
| **Quiz / exit** | evidence against the Stage 0 check | the check written at Stage 0 |

**Ordering rule:** the outline of the lesson comes from the target, *not from the textbook's chapter order*. If a block doesn't move the learner toward the checked target, cut it or move it to a handout.

---

## 2. Timing

Plan in minutes, then derive the slide count.

| Rule of thumb | Source | Use |
| --- | --- | --- |
| About **one slide per minute** for lecture-style delivery | NIU | a ceiling for content slides. It allows time for discussion and for learners to absorb |
| Ask for questions about **every 15 minutes** | NIU | also a natural break point |
| Give yourself enough time to finish. Rushing reads as disorganised | NIU | cut content rather than speed up |
| Rehearse at least once for timing and flow | NIU | rehearse with a timer |

**Activity slides break the rule.** A discussion or role-play slide can hold the room for ten minutes. Count activities by their minutes.

Worked split for 45 minutes (assessment: adjust freely):

| Min | Block | Slides |
| --- | --- | --- |
| 0–5 | Opening question + objective | 2 |
| 5–15 | Content chunk 1 + example | 6–8 |
| 15–25 | Activity (method) | 2 (rules, prompt) |
| 25–35 | Content chunk 2 + example | 6–8 |
| 35–40 | Check (poll or note check) | 2 |
| 40–45 | Summary + exit ticket | 2 |

That's about 22 slides for 45 minutes. It is **below** one-per-minute, on purpose: the activity and the check need room.

## 3. Worked example

| Field | Value |
| --- | --- |
| Target | Year 10 can scale a recipe from 4 to 6 servings without help |
| Check | 3-question exit ticket, 80% all correct |
| Method | Demonstration (the teacher scales a recipe), then pair practice |
| Opening | project: "A recipe serves 4. You have 6 guests. What do you do?" as students arrive |
| Chunk 1 | the ratio idea, with the recipe as the one example |
| Activity | pairs scale a second recipe; the teacher circulates |
| Check | Muddiest Point card: "what still confuses you?" |
| Summary | key takeaways: 3 lines |

## 4. A briefing variant

For a training briefing at work, where the audience must decide or act, the source suggests: title → executive summary (three key points) → background → current situation → key findings → proposed solution → timeline → budget summary → expected benefits → next steps → Q&A. It suits business meetings and internal briefings. It is a *briefing* shape, not a teaching shape, so use it when the target is a decision.

---

## 5. Plan B

Before the session, answer two questions:

- What do I do if the projector fails? The source suggests a printed copy with notes.
- What do I cut if I lose ten minutes? Name that block now, not while presenting.

## Check before drawing slides

- [ ] Every block moves toward the Stage 0 check
- [ ] The plan is in minutes, and the slide count follows from it
- [ ] There is a check at least every ~15 minutes
- [ ] The activity has a debrief with time reserved
- [ ] The block to cut is named
