# Tools and AI — building the deck faster without lowering the bar

Part of **Draw**. Tools save time, but they don't choose the target, and they don't check facts.

Source keys: **[COM]** COMSIAM · **[TT]** Teachers Tech (full list in [sources](sources.md)).

**Provenance:** the tool list and the workflow come from COMSIAM and Teachers Tech. The cautions are this skill's own assessment.

---

## 1. What the tools are for

| Tool | Good for | Watch for |
| --- | --- | --- |
| **PowerPoint** (with Designer, Slide Master, Icons) | building and delivering; Master keeps type and colour consistent | a template used unchanged |
| **Canva** | fast layouts from templates, lots of elements, easy for beginners | a common workflow is design in Canva → export → add animation in PowerPoint [COM]. Check that fonts and layout survive the export |
| **Google Slides / Keynote** | the same principles apply | features and animations differ, so re-check the deck on the target platform |
| **AI presentation tools** | a first draft of a structure or layout | generic slides; content that needs checking |

---

## 2. Using AI

The source lists what AI can help with: summarising the lesson, thinking up quiz questions, arranging layouts, and generating images. Tools named are ChatGPT, Canva AI and PowerPoint Designer.

| Use AI for | Then |
| --- | --- |
| A draft outline from your Stage 0 target | cut anything that doesn't move learners toward the check |
| Quiz question ideas | **verify every answer key yourself.** A wrong key teaches the wrong thing with authority |
| A first-pass summary or key-takeaways slide | compare it against your own source |
| Image ideas or generated illustrations | check relevance, style consistency, and licensing |

**Rules (assessment, with COMSIAM's own: "always review the content again"):**

- **You own the facts.** Anything AI produced goes through the same check as any other source.
- **Don't put personal data about learners into a public AI tool.** Names, grades and health details stay out.
- **Generated people aren't real people.** Don't use generated portraits as real testimonials or case-study subjects, and label generated images where it matters.
- **Write the target first.** An AI-made deck with no target is polished and aimless.

---

## When not to use

- **A short deck you can outline in five minutes.** Setting up a tool costs more than it saves.
- **Content that must be exactly right** (safety, medical, legal). Draft it from primary sources, and use tools only for layout.
