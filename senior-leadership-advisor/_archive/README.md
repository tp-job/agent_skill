# _archive — legacy files (safe to delete)

These files were the old `role/refer/` folder. Their content is **redundant** —
the full role catalog now lives in a single place: [`../references/roles.md`](../references/roles.md).

`legacy-role-prompts/` contains:
- `Role-Overview.md` — a long dump of "Act as Senior Leadership across…" prompts for ~26 disciplines.
- 9 short stubs (Backend-Engineering, Frontend-Engineering, etc.) that each duplicated a subset of the above.

Nothing in the active skill (`SKILL.md`, `00-INDEX.md`, `references/`, `roles/`) links here.

**You can delete this whole `_archive/` folder once you've confirmed you don't need the old prompt text.**
To hide it from the Obsidian graph without deleting: Settings → Files & Links → Excluded files → add `_archive`.
