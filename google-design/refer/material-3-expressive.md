# Material 3 Expressive — การออกแบบเชิงอารมณ์

> **อ่านไฟล์นี้เมื่อ:** ออกแบบหรือรีวิว UI ที่ต้องการความรู้สึก/บุคลิก ไม่ใช่แค่ใช้งานได้ — เลือก Component, สี, รูปทรง หรือ Motion ให้ "มีชีวิต" ตาม Material 3 Expressive

---

### 🔬 ที่มาของงานวิจัย

Material 3 Expressive ถือเป็น **การอัปเดตที่ผ่านการวิจัยมากที่สุดในประวัติศาสตร์ของ Google Design System** โดยเริ่มต้นจากการค้นพบของนักวิจัยฝึกงานในปี 2022 ที่กรุงมิวนิก ซึ่งตั้งคำถามว่า "ทำไม App ของ Google ถึงดูเหมือนกันหมด และน่าเบื่อเกินไป?"

> **ตัวเลขสำคัญ (ยืนยันจาก design.google):** 46 งานวิจัย · ออกแบบหลายร้อยชิ้น · ผู้เข้าร่วม 18,000+ คนทั่วโลก · ใช้เวลา 3 ปี

### 🧠 นิยาม: Expressive Design คืออะไร?

การออกแบบเชิงอารมณ์ (Expressive Design) คือการออกแบบที่ **"ทำให้คุณรู้สึกบางอย่าง"** โดยอาศัย 5 องค์ประกอบหลัก:

|องค์ประกอบ|บทบาท|
|---|---|
|**Color (สี)**|ดึงดูดความสนใจ สร้างลำดับสายตา|
|**Shape (รูปทรง)**|แสดงความสัมพันธ์ระหว่าง Element|
|**Size (ขนาด)**|บ่งบอก Priority ของ Action|
|**Motion (การเคลื่อนไหว)**|นำทางผู้ใช้ สื่อความหมาย|
|**Containment (การจัดกลุ่ม)**|ช่วยให้ผู้ใช้จัดระเบียบข้อมูลได้เร็วขึ้น|

### 📊 ผลลัพธ์จากงานวิจัย

**ความชอบของผู้ใช้:**

- ผู้ใช้ทุกกลุ่มอายุ **ชอบ Expressive Design** มากกว่า Design ปกติ
- กลุ่มอายุ 18–24 ปี มีความชอบสูงถึง **87%**
- คุณลักษณะที่ได้คะแนนสูง: "Playful", "Energetic", "Creative", "Friendly", "Positive Vibe"

**ผลต่อการรับรู้แบรนด์:**

- เพิ่ม Subculture Perception (ความรู้สึกว่าแบรนด์ทันสมัย "รู้จริง") **+32%**
- เพิ่ม Modernity (ความรู้สึกสดใหม่ก้าวหน้า) **+34%**
- เพิ่ม Rebelliousness (ความรู้สึกกล้า แหวกกรอบ) **+30%**

**ผลต่อ Usability:**

- ผู้ใช้มองเห็น UI Element หลักได้เร็วขึ้น **ถึง 4 เท่า** ด้วย Eye-tracking
- ผู้ใช้อายุ 45+ ปี สามารถค้นหา Element ได้เร็วพอกับวัยรุ่น → **ลด Age Gap**
- ปุ่ม **Send** ที่ขยายใหญ่ขึ้นและใช้สีรอง ช่วยให้ตาจับได้เร็วขึ้น 4 เท่า เทียบกับ Toolbar เล็กๆ ด้านบน

### ⚠️ บริบทยังสำคัญ (Context Still Matters)

- Expressive Design **ไม่ใช่สูตรสำเร็จ** สำหรับทุก Product
- Banking App ≠ Music App → ต้องพิจารณาความเหมาะสม
- ทดสอบแล้วพบว่าการวาง Album Art แบบสุ่มแทน List ปกติ **ทำ Usability ลดลง** แม้ดูทันสมัยกว่า
- การลบ Text Label ออกจาก Email Actions → **Usability ลดลง** เช่นกัน

### 🛠️ คำแนะนำเชิงปฏิบัติสำหรับ Designer

1. **เริ่มจาก User Need** — ไม่ใช่ความสวยงามก่อน
2. **ใช้ Material 3 Design Kit สำหรับ Figma** เพื่อทดลอง Component ใหม่
3. **Prioritize Functionality** — ความงามไม่สามารถทดแทน Core Functionality ได้
4. **ปฏิบัติตาม Accessibility Standards** — Color Contrast, Screen Reader, Navigation (ดูรายละเอียดใน `05-global-accessibility.md`)
5. **Iterate บนฐานข้อมูล** — หาจุดสมดุลระหว่าง "Freshness" และ "Familiarity"

### ✅ Checklist สำหรับ Design Review

- [ ] Component ที่เลือกสื่อ Personality ตรงกับ Brand หรือไม่
- [ ] มี Functional trade-off ที่ถูกซ่อนไว้ด้วยความสวยงามหรือไม่ (เช่น ลบ Label ออกเพื่อความ Minimal)
- [ ] ทดสอบกับกลุ่มอายุที่หลากหลายแล้วหรือยัง
- [ ] Contrast/Touch Target ยังผ่านมาตรฐาน Accessibility หรือไม่
