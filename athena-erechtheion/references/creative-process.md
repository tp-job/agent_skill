# Creativity — diverge, then converge

The third discipline. An agent asked for "a design" returns the most probable design — the template. Creativity here is a *procedure* for getting off the probable path and then choosing deliberately.

---

## 1. Diverge: 3–5 concepts that genuinely differ

Concepts must differ in **idea**, not in colour. Force the spread with a different lever per concept:

| Lever | Prompt yourself with |
| --- | --- |
| Metaphor | "What if this were a timetable / a notebook / a control panel?" |
| Inversion | "What does the obvious layout put last? Put it first." |
| Constraint | "One colour only." "No images." "Everything on one screen." |
| Borrowed world | "How would signage / print / games / instruments solve this?" |
| Extreme user | "Designed for someone using it with gloves, in sunlight, in a hurry." |

On a Material 3 foundation, also vary the expression levers (scheme variant, shape, type emphasis, motion scheme) while the invariants stay fixed. See [material-foundation](material-foundation.md) §4.

Each concept gets a name, one sentence, and a thumbnail (ASCII or a rough render). No hi-fi yet.

**BAD:** Concept A (blue), Concept B (teal), Concept C (dark mode).
**BETTER:** "Timetable" (time-first grid), "Queue" (one card at a time, swipe to act), "Wall" (every appointment visible at once, density over focus).

---

## 2. Converge: score, don't vote

Score every concept against criteria written *before* looking at the concepts — taken from the target's "judged how" and the art-direction thesis.

| Criterion (weight) | Timetable | Queue | Wall |
| --- | --- | --- | --- |
| Finds "reschedule" < 5 s (3) | 2 | 3 | 1 |
| Fits the thesis (2) | 3 | 2 | 2 |
| Works at 375px (2) | 2 | 3 | 1 |
| Build cost, inverse (1) | 3 | 2 | 2 |
| **Weighted total** | **19** | **21** | **11** |

Rules:

- **Weights come from the target, not from the concept you like.**
- **A tie is a question for the human** — ask with your default stated.
- **Salvage the runner-up.** Name the one idea from the losing concepts worth grafting onto the winner, and say why.

---

## 3. When the brief resists

| Symptom | Move |
| --- | --- |
| All concepts look alike | Swap levers — you used the same one twice |
| Nothing scores well | The criteria or the target are wrong; go back to Stage 0 |
| The lead rejects the winner | Their taste encodes an unwritten constraint — ask what it is and add it to the criteria |
| Three rejections in a row | Stop drafting; re-read the thesis with the lead |

---

## When not to apply

- A change inside an established system: the system already converged. Diverging again is re-litigation.
- Pure functional fixes (a mis-aligned label). One answer is correct; there is nothing to diverge on.

## Handoff to drafting

Pass forward: the winning concept, its scorecard, and the salvaged idea.
